Pregunta analítica

¿Qué patrones de co-ocurrencia existen entre las variables poblacionales (Cultivo), territoriales (Región) y temporales (Semestre) del dataset EVA, y cuáles combinaciones dominan el reporte agropecuario colombiano?

La Dimensión Relacional y Multivariada sintetiza los hallazgos de las tres dimensiones anteriores examinando cómo las variables interactúan entre sí. El indicador principal (IND-1/IND-2) cruza las tres variables conjuntamente —Cultivo × Región × Semestre—, no un conteo derivado de cruzar solo dos de ellas. Las tres visualizaciones muestran, además, proyecciones bidimensionales de ese mismo cruce para facilitar la lectura: Cultivo × Región (poblacional-territorial), Cultivo × Semestre (poblacional-temporal) y Región × Año (territorial-temporal). El objetivo es identificar combinaciones dominantes, cultivos transversales (presentes en múltiples regiones) y patrones de crecimiento diferenciados por región.

{# --- Interpretaciones --- #}
{{ sec_head(6, "Interpretación de cada visualización") }}
{% call interp_item(1, "VIZ-1", "success", "Solo 52 de 90 ternas están pobladas") %}

De las 90 ternas posibles (6 cultivos × 5 regiones × 3 tipos de semestre), solo 52 (57.8 %) tienen al menos un registro. El cálculo cuenta las ternas Cultivo × Región × Semestre con registros, sobre el total de combinaciones posibles (6×5×3).

Existe una fuerte especialización: no todos los cultivos se evalúan en todas las regiones y semestres. Esto permite identificar huecos de cobertura, aunque una terna vacía puede reflejar tanto una ausencia real del cultivo como un subregistro.

{% endcall %} {% call interp_item(2, "VIZ-2", "info", "La terna líder es Maíz × Andina × Primer semestre") %}

La combinación más frecuente es Maíz × Andina × Primer semestre, con 5.469 registros (11.2 %) del total; el par Maíz × Andina acumula 10.562 registros (21.6 %). El cálculo identifica el máximo de registros entre las 90 ternas posibles.

El maíz andino del primer semestre es el perfil dominante del registro agropecuario, y constituye un foco natural para el análisis y la política pública. Esta medida es frecuencia de evaluación, no volumen de producción.

{% endcall %} {% call interp_item(3, "VIZ-3", "warning", "El maíz es el cultivo más transversal") %}

El Maíz está presente en las 5 regiones geográficas: 29 de los 30 pares posibles cultivo×región tienen al menos un registro. Sin embargo, al incorporar el semestre como tercera variable, las combinaciones activas caen a 52 de 90.

Al cruzar solo dos variables casi todo se combina; es la tercera variable (semestre) la que revela los huecos reales de cobertura, lo que justifica el análisis multivariado frente al bivariado. "Activo" aquí significa al menos un registro, no mide intensidad de producción.

{% endcall %}

{# --- Limitación y decisión --- #}
{{ sec_head(8, "Limitación y decisión") }} {% set limitacion %} El análisis relacional se construye sobre cruces de frecuencias de registros, no sobre variables de producción real (toneladas, hectáreas). Las relaciones identificadas pueden ser artefactos del proceso de reporte del sistema EVA: una región con más registros puede simplemente tener un sistema de reporte más exhaustivo, no necesariamente mayor actividad agrícola real. Adicionalmente, la variable Región es derivada mediante un mapeo manual y agrupa realidades agroecológicas heterogéneas dentro de cada región. Por último, los análisis de co-ocurrencia no establecen causalidad: que {{ top_combo_cultivo }} sea frecuente en {{ top_combo_region }} durante el {{ top_combo_sem }} no explica por qué, ni implica que deba mantenerse así en el futuro. {% endset %} {% set decision %} El análisis multidimensional muestra que el dataset EVA tiene una estructura relacional compleja pero comprensible: {{ active_combos }} ternas cultivo×región×semestre activas de {{ max_combos }} posibles, una terna dominante clara ({{ top_combo_cultivo }} × {{ top_combo_region }} × {{ top_combo_sem }}) y un cultivo transversal identificado ({{ transversal_cultivo }}, {{ transversal_regions }} regiones). Se recomienda usar el cruce Cultivo × Región × Semestre (ya calculado en IND-1/IND-2) como estratificación base para cualquier modelo predictivo, en lugar de tratar las variables de forma independiente. El cultivo {{ transversal_cultivo }} debe recibir tratamiento especial como variable de referencia en comparaciones inter-regionales, y los modelos deben incluir términos de interacción explícitos entre Cultivo, Región y Semestre para capturar la heterogeneidad del territorio colombiano. {% endset %} {{ limite_decision(limitacion, decision) }}
