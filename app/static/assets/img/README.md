# Assets de imagen

Los íconos del sitio son SVG en línea dentro de las plantillas (marca,
tarjetas, navegación) para permitir animarlos con CSS/JS sin depender de
archivos externos. Si agregas imágenes rasterizadas (fotografías de
cultivos, capturas, etc.), colócalas en esta carpeta y referéncialas con
`url_for('static', filename='assets/img/tu_imagen.png')`.
